# Bank Management System

Bank Management System made using Python.

This project allows users to create and manage bank accounts. Account data is stored in a JSON file, so the data remains available even after closing the program.

## Features

- Create a new bank account
- Login using account number and PIN
- Deposit money
- Withdraw money
- Check account details
- Update account details
- Delete an account
- View transaction history
- PIN hashing using SHA-256
- Account numbers are generated automatically
- Account data is stored in `data.json`

## Technologies Used

- Python
- JSON
- File Handling
- OOP
- Hashlib
